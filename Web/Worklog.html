Opening this file

Open Worklog.html in a full browser on Windows to use the dashboard and records. iPhone Files previews may not run the app; use an HTTPS-hosted copy in Safari for browser GPS and camera access. All code is included in this file; no fonts, libraries, analytics or record uploads are loaded from the internet.

GPS needs browser permission and a supported secure context. Camera capture uses the phone’s file/camera picker and does not perform OCR. Supplier and amounts are entered manually.

The accountant ZIP includes trip and invoice registers, selected-year originals and explanatory notes. A work-only GPS register is not a complete ATO logbook. Your accountant determines the records and retention periods needed.
