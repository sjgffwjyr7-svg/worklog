# Farmer guide — visual revision preview

`VMS300_Control_Highlights_Preview.mp4` is a short **silent visual design preview**, not a complete operating procedure or the new narrated farmer guide. Every frame is labelled “VISUAL PREVIEW • NARRATION PENDING”. It demonstrates separate button highlights and the distinction between TAP ONCE, PRESS AND HOLD and PRESS TOGETHER. Its timing demonstrates the visual design only; it is not aligned to narration.

The revised narration includes the requested greeting and light farm humour. The technical procedure and safety instructions remain based on the uploaded DeLaval VMS V300 Instruction Book, §6.2 pp248–256, with Manual (Closed Stall) prerequisites and empty-stall testing checks. The pictured station uses the left-oriented panel; the right-oriented station is mirrored.

The controller images are JPEG exports of the existing **generated, annotated derivative of the supplied controller photograph**, not untouched original photos or live machine states. Close-ups retain the printed symbols. No lamp states have been repainted. Available source details and checksums are recorded in image-assets.json. The original ZIP and DNG exceeded the cloud transfer limit, so clean originals could not be obtained for this edit. Other full-guide equipment illustrations and screen references remain explicitly identified as manual sources; actual alignment/contact/tube-position footage is still unavailable.

The user authorised using their own voice in “Reds HillBilly Shot.mp4”. The isolated custom-voice software imports and its watermark function work, but this cloud instance returns HTTP CONNECT 403 for the official model host. No speech has been synthesised with that model, and no exact likeness is claimed. The rejected stock voice is not substituted. Required model-download domains have been saved to the cloud environment draft; the user must review, save and publish the environment settings before the voice test can proceed.

The current narrated guide at `exports/VMS300_Farmer_Guide.mp4`, the adult edition and the voice samples are preserved. This folder does not replace any of them.

To save the preview, sign into GitHub with access to this repository, open the MP4 file and choose **Download raw file**. Anonymous access to this repository may return 404. The preview contains no audio track by design.
